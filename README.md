# python_coffee_machine_using_oop


A simple Coffee Machine project built using Python and Object-Oriented Programming (OOP).

The program simulates a coffee machine where users can order drinks, insert coins, check available resources and receive their coffee.

Features

Three drink options: Espresso, Latte and Cappuccino. Coin processing and change calculation, Resource availability checking.
Tracks available ingredients. Displays a resource report.

Concepts Used

Classes and Objects, Methods and Attributes, Object-Oriented Programming, Loops and Conditional Statements

How to Run

python main.py

This project was built as part of my journey to learn Python and understand OOP concepts through practical implementation.
